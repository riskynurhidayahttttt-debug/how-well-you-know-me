# A Little Love Story — Pipo Studio Demo 01

## Cara menjalankan
1. Ekstrak folder `how-well-you-know-me` ke dalam `Pipo_Studio/demos/`.
2. Buka folder ini di VS Code.
3. Jalankan `index.html` dengan Live Server (klik kanan > Open with Live Server).

## Isi folder
- `index.html` — struktur halaman
- `style.css` — tampilan dan animasi
- `script.js` — pertanyaan, jawaban, skor, dan hasil

Catatan: pertanyaan dan jawaban di `script.js` masih contoh dan bisa disesuaikan untuk tiap pelanggan.
